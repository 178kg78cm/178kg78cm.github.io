## 알고리즘

코딩테스트를 준비하면서 공부한 알고리즘과 풀이를 주제별로 모아 둔 목차다. 언어는 C++을 기준으로 한다.

## 공부 순서

1. **시간 복잡도**로 입력 크기에 맞는 풀이 수준을 먼저 판단한다.
2. 문제 유형을 파악하고(탐색, 그래프, 해시 등) 맞는 알고리즘을 고른다.
3. 직접 풀고, 막힌 부분과 실수한 부분을 글로 남긴다.

정렬된 범위에서 탐색 범위를 절반씩 줄여 `O(log N)`에 답을 찾는다. "답이 될 수 있는 값"을 이진 탐색하는 **매개변수 탐색(Parametric Search)** 이 핵심이다.

## 유형별 선택 기준

| 상황 | 알고리즘 |
| --- | --- |
| 정렬된 데이터에서 값 찾기, 최솟값/최댓값 조건 만족 | 이진 탐색 |
| 모든 경우의 수, 경로 존재 여부 | DFS (백트래킹) |
| 가중치 없는 최단 거리, 최소 이동 횟수 | BFS |
| 빠른 존재 확인, 개수 세기 | 해시 (`unordered_map`, `unordered_set`) |
