## SPI vs I2C vs UART 비교

## 1. SPI (Serial Peripheral Interface)
- **고속 직렬 통신** (1~50 MHz)
- **마스터-슬레이브 구조**, Full-Duplex 지원
- **4개 이상의 핀 필요** (SCLK, MOSI, MISO, SS)
- **속도가 빠르지만, 배선이 많아짐**
- **사용 예시**: SD 카드, LCD 디스플레이, 고속 센서

## 2. I2C (Inter-Integrated Circuit)
- **저속 직렬 통신** (100 kHz ~ 3.4 MHz)
- **멀티 마스터-슬레이브 지원**, Half-Duplex
- **2개의 핀만 필요** (SDA, SCL)
- **속도는 느리지만, 여러 장치를 쉽게 연결 가능**
- **사용 예시**: 온도 센서, EEPROM, RTC 모듈

## 3. UART (Universal Asynchronous Receiver/Transmitter)
- **비동기 직렬 통신** (보통 9600~115200 bps)
- **시작/정지 비트 사용**, Full-Duplex (TX, RX 선이 따로 있음)
- **2개의 핀 필요** (TX, RX)
- **간단한 연결이 가능하지만, 양쪽 보오레이트를 맞춰야 함** (클럭선이 없음)
- **사용 예시**: 시리얼 모니터, 블루투스 모듈, GPS 모듈

## 요약
|  | SPI | I2C | UART |
|--|------|------|------|
| **속도** | 빠름 | 중간 | 느림 |
| **통신 방식** | 동기 (클럭 필요) | 동기 (클럭 필요) | 비동기 |
| **Full/Half-Duplex** | Full | Half | Full |
| **핀 개수** | 최소 4개 | 2개 | 2개 |
| **멀티 슬레이브** | 가능 (SS 핀 필요) | 가능 (주소로 구분) | 불가능 (1:1) |
| **사용 예시** | SD 카드, LCD | 센서, EEPROM | 블루투스, GPS |


5개의 핀만으로도 데이터를 전달할 수 있도록 위의 3개의 통신방법 중 하나를 선택해야한다.
우리는 이번에 SPI를 사용한다.

임베디드 시스템 개발에서 하드웨어 선택과 소프트웨어 설계로 이어지는 과정이 매우 중요하다. 선택된 하드웨어 스펙에 맞춰서 적절한 소프트웨어 설계 방식을 고르는 것이 핵심이다.

## 실습 : 4자리 7-Segment 스톱워치

### 하드웨어 구성

- **4자리 7-Segment(FND) 모듈** : 내부에 **74HC595 시프트 레지스터** 2개가 있어서, 선 3개(SCLK, RCLK, DIO)로 4자리를 모두 제어한다.
- **버튼 2개** : 외부 인터럽트(ERU)로 연결. ISR0 = 시작/정지, ISR1 = 리셋

| 핀 | 역할 | SPI로 보면 |
| --- | --- | --- |
| `DIO` (P00.2) | 직렬 데이터 | MOSI |
| `SCLK` (P00.0) | 시프트 클럭. 상승 에지마다 DIO의 1비트를 밀어 넣음 | SCK |
| `RCLK` (P00.1) | 래치 클럭. 상승 에지에 모은 8비트를 출력 핀으로 내보냄 | SS(CS) 역할 |

SPI 주변장치를 쓰지 않고 **GPIO를 직접 토글해서 SPI 타이밍을 만드는 방식(Bit-banging)** 으로 구현했다.

### 동작 원리

```text
send(X)      : MSB부터 8비트를 DIO에 놓고 SCLK를 Low → High (8번 반복)
send_port(X, port)
             : send(세그먼트 패턴) → send(자리 선택 비트) → RCLK Low → High (래치)
```

- 첫 번째 바이트 `_LED_0F[n]`는 **어떤 숫자 모양을 켤지**(세그먼트 a~g, dp)다. 공통 애노드 방식이라 0인 비트의 세그먼트가 켜진다. (`0xC0` = 숫자 0)
- 두 번째 바이트 `0x1, 0x2, 0x4, 0x8`은 **몇 번째 자리에 표시할지**다.
- 한 번에 한 자리만 켤 수 있으므로, 4자리를 빠르게 번갈아 켜는 **다이나믹 구동(Multiplexing)** 으로 사람 눈에는 4자리가 동시에 켜진 것처럼 보이게 한다. 갱신이 느려지면 깜빡임이 보인다.

### 소프트웨어 구성

- **FSM** : `STOP`, `START`, `RESET` 상태. 버튼 ISR은 상태만 바꾼다. ([FSM 정리](/2025-02-13-임베디드MCU-Timer-Interrupt/))
- **Task Scheduler** : STM 타이머로 1ms / 10ms / 100ms / 1000ms 주기 태스크를 나눠, 숫자 증가와 표시 갱신 주기를 분리했다.
- 카운트 값을 자릿수(n1~n4)로 나눠 `send_port()`로 각 자리에 출력한다.

int core0_main(void){
    IfxCpu_enableInterrupts();
    
    /* !!WATCHDOG0 AND SAFETY WATCHDOG ARE DISABLED HERE!!
     * Enable the watchdogs and service them periodically if it is required
     */
    IfxScuWdt_disableCpuWatchdog(IfxScuWdt_getCpuWatchdogPassword());
    IfxScuWdt_disableSafetyWatchdog(IfxScuWdt_getSafetyWatchdogPassword());
    
    /* Wait for CPU sync event */
    IfxCpu_emitEvent(&g_cpuSyncEvent);
    IfxCpu_waitEvent(&g_cpuSyncEvent, 1);

    initGPIO();
    initERU();
    Driver_Stm_Init();
    send_port(_LED_0F[1], 0xF);
    while(1)
    {
        int n1, n2, n3, n4;
        for(int n=0;n<9999;){
            switch(state){
                case STOP:
                    break;
                case START:
                    n++;
                    break;
                case RESET:
                    state=pstate;
                    n=0;
                    break;
                default:
                    n=0;
                    break;
            }
            n1 = (int) n%10;
            n2 = (int) (n%100)/10;
            n3 = (int) (n%1000)/100;
            n4 = (int) (n%10000)/1000;
           for(int j=0;j<50;j++){
                send_port(_LED_0F[n1], 0x1);
                send_port(_LED_0F[n2], 0x2);
                send_port(_LED_0F[n3], 0x4);
                send_port(_LED_0F[n4], 0x8);
            }
        }
//        AppScheduling();
    }
    return (1);
}

void initGPIO(void){
    P02_IOCR0.U &= ~(0x1F << PCn_0_IDX);
    P02_IOCR0.U |= 0x02;                // SW D2
    P02_IOCR0.U &= ~(0x1F << PCn_1_IDX);
    P02_IOCR0.U |= 0x02 << PCn_1_IDX;   // SW D3

    P10_IOCR0.U &= ~(0x1F << PCn_2_IDX);
    P10_IOCR0.U |= 0x10 << PCn_2_IDX;
    P10_IOCR0.U &= ~(0x1F << PCn_1_IDX);
    P10_IOCR0.U |= 0x10 << PCn_1_IDX;
    P10_IOCR0.U &= ~(0x1F << PCn_2_IDX);
    P10_IOCR0.U |= 0x10 << PCn_2_IDX;

    P10_IOCR0.U &= ~(0x1F << PCn_1_IDX);
    P10_IOCR0.U |= 0x10 << PCn_1_IDX;

    IfxPort_setPinModeOutput(SCLK.port, SCLK.pinIndex, IfxPort_OutputMode_pushPull, IfxPort_OutputIdx_general);
    IfxPort_setPinModeOutput(DIO.port, DIO.pinIndex, IfxPort_OutputMode_pushPull, IfxPort_OutputIdx_general);
    IfxPort_setPinModeOutput(RCLK.port, RCLK.pinIndex, IfxPort_OutputMode_pushPull, IfxPort_OutputIdx_general);
}

void AppTask1000ms(void)
{
    static int flag = 0;
    if(flag == 0)
    {
        IfxPort_setPinLow(IfxPort_P10_2.port, IfxPort_P10_2.pinIndex);
        flag = 1;
    }
    else
    {
        IfxPort_setPinHigh(IfxPort_P10_2.port, IfxPort_P10_2.pinIndex);
        flag = 0;
    }
    stTestCnt.u32nuCnt1000ms++;

}

void AppScheduling(void){
    if(stSchedulingInfo.u8nuScheduling1msFlag == 1u)
    {
        stSchedulingInfo.u8nuScheduling1msFlag = 0u;
        AppTask1ms();

        if(stSchedulingInfo.u8nuScheduling10msFlag == 1u)
        {
            stSchedulingInfo.u8nuScheduling10msFlag = 0u;
            AppTask10ms();
        }

        if(stSchedulingInfo.u8nuScheduling100msFlag == 1u)
        {
            stSchedulingInfo.u8nuScheduling100msFlag = 0u;
            AppTask100ms();
        }
        if(stSchedulingInfo.u8nuScheduling1000msFlag == 1u)
        {
            stSchedulingInfo.u8nuScheduling1000msFlag = 0u;
            AppTask1000ms();
        }
    }
}


void send_port(uint8_t X, uint8_t port){
    send(X);
    send(port);
    IfxPort_setPinLow(RCLK.port,RCLK.pinIndex);
    IfxPort_setPinHigh(RCLK.port,RCLK.pinIndex);
}
void send(uint8_t X){
    for(int i=8;i>=1;i--){
        if(X & 0x80) IfxPort_setPinHigh(DIO.port, DIO.pinIndex);
        else IfxPort_setPinLow(DIO.port, DIO.pinIndex);

        X <<= 1;
        IfxPort_setPinLow(SCLK.port,SCLK.pinIndex);
        IfxPort_setPinHigh(SCLK.port,SCLK.pinIndex);
    }
}

void initERU(void){
    SCU_EICR1.U &= ~(0x7 << EXIS0_IDX);
    SCU_EICR1.U |= 0x1 << EXIS0_IDX;
    SCU_EICR1.U |= 0x1 << FEN0_IDX;
    SCU_EICR1.U |= 0x1 << EIEN0_IDX;
    SCU_EICR1.U &= ~(0x7 << INP0_IDX);

    SCU_EICR1.U &= ~(0x7 << (EXIS0_IDX + 16));
    SCU_EICR1.U |= 0x2 << (EXIS0_IDX + 16);
    SCU_EICR1.U |= 0x1 << (FEN0_IDX + 16);
    SCU_EICR1.U |= 0x1 << (EIEN0_IDX + 16);
    SCU_EICR1.U &= ~(0x7 << (INP0_IDX + 16));
    SCU_EICR1.U += 0x1 << (INP0_IDX + 16); // OGU1번 사용

    SCU_IGCR0.U &= ~(0x3 << IGP0_IDX);
    SCU_IGCR0.U |= 0x1 << IGP0_IDX;

    SCU_IGCR0.U &= ~(0x3 << (IGP0_IDX+16));
    SCU_IGCR0.U |= 0x1 << (IGP0_IDX+16);

    SRC_SCU_SCU_ERU0.U &= ~0XFF;
    SRC_SCU_SCU_ERU0.U |= 0X10;
    SRC_SCU_SCU_ERU0.U |= 0x1 << SRE_IDX;
    SRC_SCU_SCU_ERU0.U &= ~(0x3 << TOS_IDX);

    SRC_SCU_SCU_ERU1.U &= ~0XFF;
    SRC_SCU_SCU_ERU1.U |= 0X20;
    SRC_SCU_SCU_ERU1.U |= 0x1 << SRE_IDX;
    SRC_SCU_SCU_ERU1.U &= ~(0x3 << TOS_IDX);

}
